# svsim

A SystemVerilog simulator in Rust: parse a synthesizable subset with
[sv-parser](https://crates.io/crates/sv-parser), lower it into an owned HIR,
elaborate the design, and simulate it with four-state logic (`0/1/X/Z`),
driven either as a library or through JSON regression suites.

```text
cargo test                                        # the gate: unit + corpus + CLI
cargo run -p svsim-cli -- parts/basic/full_adder.sv
cargo run -p svsim-cli -- --json-test parts/basic/full_adder.json parts/basic/full_adder.sv
```

## Layout

- `crates/svsim` — the library: frontend, HIR, validation, elaboration,
  four-state runtime, JSON harness.
- `crates/svsim-cli` — thin CLI wrapper (`svsim` binary).
- `parts/` — the compatibility corpus and behavior oracle: every directory
  except `parts/failing` (gated must-fail negative corpus) and `parts/roms`
  (assets) must stay green, enforced by `cargo test`
  (`crates/svsim/tests/corpus_gate.rs`). Includes an educational 8-bit CPU
  stack (`overture`), SAP-1/2/3 ports, an RV32I demo core, and upstream
  picorv32.
- `docs/tests/` — committed corpus reports, regenerated by `./test.sh`.
- `wiki/` — maintained knowledge base (architecture, status, testing,
  roadmap); start at [wiki/index.md](wiki/index.md).
